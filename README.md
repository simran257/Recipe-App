# 🍽️ Recipe Sharing Platform

A full-stack **Recipe Sharing Platform** built using **HTML, CSS, JavaScript, Node.js, Express.js, and MongoDB**.  
This project provides a complete RESTful API to **create, read, update, delete, and share recipes**.

---

## 🚀 Features

- 📝 Add new recipes
- ✏️ Edit / Update recipes
- ❌ Delete recipes
- 🌐 RESTful API integration
- 📦 MongoDB database storage
- 🧪 Tested using Postman
- 💻 Simple frontend using HTML, CSS, JS



## 🛠️ Tech Stack

**Frontend:**
- HTML
- CSS
- JavaScript

**Backend:**
- Node.js
- Express.js

**Database:**
- MongoDB (Mongoose)

**Tools:**
- Postman (API testing)
